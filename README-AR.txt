FAOZAN FISH PWA — ملفات التثبيت

الملفات التي يجب رفعها إلى جذر مستودع faozan-app/faozan-games:
1. index.html — تحديث الصفحة الرئيسية مع الحفاظ على زر لعبة الأرقام.
2. fish.html — نسخة اللعبة نفسها مع ربط PWA فقط؛ لم تتغير آلية اللعب.
3. fish-manifest.webmanifest
4. fish-sw.js
5. apple-touch-icon.png
6. fish-icon-192.png
7. fish-icon-512.png

لا تحذف game.html أو CNAME أو أي ملف آخر.
بعد رفع الملفات تأكد من أن الصفحة الرئيسية تعرض لعبتين.
على الآيفون: اضغط INSTALL FISH ثم OPEN FISH GAME، ومن Safari اضغط مشاركة > إضافة إلى الشاشة الرئيسية > إضافة.
على الأندرويد: قد يعرض زر INSTALL FISH مطالبة التثبيت، وإلا افتح القائمة واختر تثبيت التطبيق.
ملاحظة: التثبيت من iOS يحتاج تنفيذ المستخدم لخطوات النظام، وليس تلقائيا من زر الويب.
